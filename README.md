A single-line excuse for a missed deadline, delivered by someone who treats
red flags the way most people treat deadlines: with total confidence and zero
hesitation. `main.ts` writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
